# The bundled molecular dynamics example

The bundled molecular dynamics example

## Usage

``` r
.md_example()
```

## Value

A list of two data frames read with
[`read_xvg()`](https://j-andrews7.github.io/sciVizModules/reference/read_xvg.md):
`trajectory` (the three RMSD replicas and the radius of gyration, with
`metric` naming each) and `rmsf` (per-residue fluctuations).
