# Y-axis title of a survival curve

Y-axis title of a survival curve

## Usage

``` r
.km_axis_title(fun = NULL)
```

## Arguments

- fun:

  The curve transformation, as for
  [`.km_frame()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_km_frame.md).

## Value

A string.
