# Built-in input defaults for the cnSegmentPlot module

Internal helper shared by
[`cnSegmentPlotInputsUI()`](https://j-andrews7.github.io/sciVizModules/reference/cnSegmentPlotInputsUI.md)
and
[`cnSegmentPlotServer()`](https://j-andrews7.github.io/sciVizModules/reference/cnSegmentPlotServer.md),
which must fall back to the same values when building and when resetting
the controls. It lives here so the two stay in step.

## Usage

``` r
.cn_seg_base_defaults()
```

## Value

A named list of default input values.
