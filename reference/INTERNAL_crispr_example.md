# The bundled MAGeCK examples

The bundled MAGeCK examples

## Usage

``` r
.crispr_example(type = c("rra", "mle"))
```

## Arguments

- type:

  `"rra"` for the simulated `mageck test` gene summary, `"mle"` for the
  simulated `mageck mle` one.

## Value

The gene summary in `inst/extdata`, read with
[`read_mageck()`](https://j-andrews7.github.io/sciVizModules/reference/read_mageck.md).
