# The elbow of a scree curve

Uses
[`PCAtools::findElbowPoint()`](https://rdrr.io/pkg/PCAtools/man/findElbowPoint.html)
when PCAtools is installed.

## Usage

``` r
.pca_elbow(p)
```

## Arguments

- p:

  A `pca` object.

## Value

The 1-based index of the elbow component, or `NULL`.
