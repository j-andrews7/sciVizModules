# The Annotations tab of a dittoSeq module

The Annotations tab of a dittoSeq module

## Usage

``` r
.ditto_annotation_inputs_ui(ns, defaults, object, note = NULL)
```

## Arguments

- ns:

  The module's namespace function.

- defaults:

  The module's defaults.

- object:

  The dittoSeq-compatible object.

- note:

  Optional further text for the Annotate By tooltip.

## Value

The inputs of
[`VizModules::uniform_annotation_inputs_ui()`](https://j-andrews7.github.io/VizModules/reference/uniform_annotation_inputs_ui.html).
