# The 96 single-base-substitution channels

Named and ordered as MutationalPatterns (`mut_matrix()`), maftools
(`trinucleotideMatrix()`) and COSMIC name them: class by class, the 5'
base outer and the 3' base inner, e.g. `"A[C>A]A"`, `"A[C>A]C"`, ...

## Usage

``` r
.sbs96_channels()
```

## Value

A character vector of 96 channel names.
