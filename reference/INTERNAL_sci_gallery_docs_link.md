# A link to a module's reference page on the package website

A link to a module's reference page on the package website

## Usage

``` r
.sci_gallery_docs_link(entry, info, label = "Docs")
```

## Arguments

- entry:

  A
  [`.sci_module_showcase()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_sci_module_showcase.md)
  entry.

- info:

  The list from
  [`.sci_gallery_package_info()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_sci_gallery_package_info.md).

- label:

  The link text.

## Value

An `<a>` tag opening the module's `*InputsUI()` reference page, which
lists every control and its default.
