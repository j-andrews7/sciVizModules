# Axis title for a component, with its explained variance

Axis title for a component, with its explained variance

## Usage

``` r
.pca_axis_title(p, pc)
```

## Arguments

- p:

  A `pca` object.

- pc:

  A component name.

## Value

E.g. `"PC1 (40.8% variance)"`, or `pc` unchanged when it is not a
component.
