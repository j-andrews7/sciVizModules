# Input UI components for the michaelisMenten module

This should be placed in the UI where the inputs should be shown, with
an `id` that matches the `id` used in the
[`michaelisMentenServer()`](https://j-andrews7.github.io/sciVizModules/reference/michaelisMentenServer.md)
and
[`michaelisMentenOutputUI()`](https://j-andrews7.github.io/sciVizModules/reference/michaelisMentenOutputUI.md)
functions.

## Usage

``` r
michaelisMentenInputsUI(
  id,
  data,
  defaults = NULL,
  title = "Michaelis-Menten Settings",
  columns = 2
)
```

## Arguments

- id:

  The ID for the Shiny module.

- data:

  The plotting data frame used to populate the axis column choices.

- defaults:

  A named list of default values for the inputs.

- title:

  An optional title for the UI grid.

- columns:

  Number of columns for the UI grid.

## Value

A Shiny tagList containing the UI elements.

## Details

The user inputs for this module are separated from the outputs to allow
for more flexible UI design. The module draws the observed points from
the plotting data and overlays a pre-computed fitted line (the `model`
data frame). When a `stats` object is supplied to the server, the
estimated Michaelis constant (K) and maximum velocity (Vmax) are
annotated onto the plotly figure.

## See also

[`michaelisMentenPlot()`](https://j-andrews7.github.io/sciVizModules/reference/michaelisMentenPlot.md),
[`michaelisMentenOutputUI()`](https://j-andrews7.github.io/sciVizModules/reference/michaelisMentenOutputUI.md),
[`michaelisMentenServer()`](https://j-andrews7.github.io/sciVizModules/reference/michaelisMentenServer.md),
[`michaelisMentenApp()`](https://j-andrews7.github.io/sciVizModules/reference/michaelisMentenApp.md)
