# Reset a dittoSeq module's Annotations tab

Reset a dittoSeq module's Annotations tab

## Usage

``` r
.ditto_reset_annotations(session, defaults, object, annotations)
```

## Arguments

- session:

  The module's session.

- defaults:

  The module's defaults.

- object:

  The dittoSeq-compatible object.

- annotations:

  The list from
  [`.ditto_annotation_state()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_ditto_annotation_state.md).

## Value

Invisibly `NULL`.
