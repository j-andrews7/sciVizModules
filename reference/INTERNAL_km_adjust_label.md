# Display name of a p-value adjustment method

Display name of a p-value adjustment method

## Usage

``` r
.km_adjust_label(method)
```

## Arguments

- method:

  A [`stats::p.adjust()`](https://rdrr.io/r/stats/p.adjust.html) method.

## Value

A short name, such as `"Holm"` or `"BH"`.
