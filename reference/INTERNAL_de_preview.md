# Sample metadata of a deHeatmap input, for a read-only preview

Sample metadata of a deHeatmap input, for a read-only preview

## Usage

``` r
.de_preview(x)
```

## Arguments

- x:

  A deHeatmap input (see
  [`.de_resolve()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_de_resolve.md)).

## Value

The experiment's `colData` as a data frame.
