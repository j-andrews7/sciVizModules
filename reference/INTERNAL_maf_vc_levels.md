# Variant classes and their colours for a mutation module's picker

Variant classes and their colours for a mutation module's picker

## Usage

``` r
.maf_vc_levels(m, multi.hit = FALSE)
```

## Arguments

- m:

  A result of
  [`.maf_table()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_maf_table.md).

- multi.hit:

  Logical; include `"Multi_Hit"`.

## Value

The non-synonymous classes present, in maftools' colour order.
