# Default inputs for the alphafoldConfidence module

Shared by the UI and the Reset handler. User values win.

## Usage

``` r
.af_defaults(x, defaults = NULL)
```

## Arguments

- x:

  An object from
  [`read_alphafold()`](https://j-andrews7.github.io/sciVizModules/reference/read_alphafold.md).

- defaults:

  A named list of user defaults, or `NULL`.

## Value

A named list of defaults.
