# Plot output for a native plot module

Plot output for a native plot module

## Usage

``` r
.sci_plot_output_ui(id, name, resizable = TRUE, height = "400px")
```

## Arguments

- id:

  The module id.

- name:

  The module name (the output id).

- resizable:

  Logical; wrap in
  [`shinyjqui::jqui_resizable()`](https://yang-tang.github.io/shinyjqui/reference/Interactions.html).

- height:

  CSS height of the output.

## Value

The output UI.
