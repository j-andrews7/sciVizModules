# Gene set results of a GSEA input, for a read-only preview

Gene set results of a GSEA input, for a read-only preview

## Usage

``` r
.gsea_preview(x)
```

## Arguments

- x:

  An fgsea bundle or clusterProfiler `gseaResult`.

## Value

Its results table, or the gene sets and their sizes when it has none.
