# Stop when an object is not dittoSeq-compatible

Stop when an object is not dittoSeq-compatible

## Usage

``` r
.assert_ditto_object(object, arg = "object")
```

## Arguments

- object:

  An object to validate.

- arg:

  The argument name to report in the error message.

## Value

Invisibly `TRUE` when valid; otherwise throws an error.
