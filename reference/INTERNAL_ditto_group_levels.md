# Discrete levels of a metadata column, for palette groups

Discrete levels of a metadata column, for palette groups

## Usage

``` r
.ditto_group_levels(object, meta)
```

## Arguments

- object:

  A dittoSeq-compatible object.

- meta:

  The name of a metadata column.

## Value

A character vector of levels, or `character(0)`.
