# Named Up/Down/n.s. colour vector from a volcano/MA defaults list

Named Up/Down/n.s. colour vector from a volcano/MA defaults list

## Usage

``` r
.de_group_colors(defaults)
```

## Arguments

- defaults:

  A defaults list as returned by
  [`.volcano_defaults()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_volcano_defaults.md)
  or
  [`.ma_defaults()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_ma_defaults.md).

## Value

A named character vector with `Up`, `Down`, and `n.s.` entries.
