# Assays a dittoSeq object offers for a heatmap

Assays a dittoSeq object offers for a heatmap

## Usage

``` r
.ditto_assays(object)
```

## Arguments

- object:

  A dittoSeq-compatible object.

## Value

The assay names of a `SummarizedExperiment`-family object, or
`character(0)` (dittoSeq then picks the default assay itself).
