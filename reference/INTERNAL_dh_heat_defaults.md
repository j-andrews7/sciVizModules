# Heatmap defaults for the dittoHeatmap module

Heatmap defaults for the dittoHeatmap module

## Usage

``` r
.dh_heat_defaults(frame, object, d, defaults = NULL)
```

## Arguments

- frame:

  A
  [`.ditto_heatmap_data()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_ditto_heatmap_data.md)
  result.

- object:

  The dittoSeq object.

- d:

  The wrapper defaults from
  [`.dh_defaults()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_dh_defaults.md).

- defaults:

  The caller's defaults.

## Value

Defaults for the wrapped heatmap module.
