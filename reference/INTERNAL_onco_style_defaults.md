# Axes-tab defaults for the oncoPlot module

A tile grid reads better without gridlines or axis lines. User values
win.

## Usage

``` r
.onco_style_defaults(defaults = NULL)
```

## Arguments

- defaults:

  A named list of user defaults, or `NULL`.

## Value

`defaults` with the oncoplot's axis styling filled in.
