# The deHeatmap wrapper's inputs, read from the session

The deHeatmap wrapper's inputs, read from the session

## Usage

``` r
.de_read_inputs(input, isolate_fn, d)
```

## Arguments

- input:

  The module's input.

- isolate_fn:

  The isolation helper.

- d:

  Fallback values, from
  [`.de_defaults()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_de_defaults.md).

## Value

A list of the wrapper's input values.
