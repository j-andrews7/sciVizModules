# Validate a GSEA input for the module

Validate a GSEA input for the module

## Usage

``` r
.assert_gsea(x, arg = "data")
```

## Arguments

- x:

  The input.

- arg:

  Argument name for error messages.

## Value

The normalised bundle from
[`.gsea_input()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_gsea_input.md).
