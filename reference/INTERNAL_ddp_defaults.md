# Default inputs for the dittoDotPlot module

Shared by the UI and the Reset handler. User values win.

## Usage

``` r
.ddp_defaults(object, defaults = NULL)
```

## Arguments

- object:

  A dittoSeq-compatible object.

- defaults:

  A named list of user defaults, or `NULL`.

## Value

A named list of defaults.
