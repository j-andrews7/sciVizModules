# Pathways to show by default

Pathways to show by default

## Usage

``` r
.gsea_default_pathways(x, n = 3)
```

## Arguments

- x:

  A bundle from
  [`.gsea_input()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_gsea_input.md).

- n:

  How many.

## Value

The `n` most significant pathways when results are available, otherwise
the first `n`.
