# Sample annotations usable as oncoplot tracks

Sample annotations usable as oncoplot tracks

## Usage

``` r
.maf_track_cols(m)
```

## Arguments

- m:

  A result of
  [`.maf_table()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_maf_table.md).

## Value

The names of the clinical columns with fewer than 50 distinct values, or
numeric ones.
