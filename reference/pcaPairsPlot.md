# Pairs plot of a PCAtools `pca` object

The interactive counterpart of
[`PCAtools::pairsplot()`](https://rdrr.io/pkg/PCAtools/man/pairsplot.html):
a lower-triangle grid of sample-score scatters for every pair of the
chosen components, sharing one x-axis per column and one y-axis per row,
coloured and shaped by sample metadata.

## Usage

``` r
pcaPairsPlot(
  pcaobj,
  components = NULL,
  color.by = NULL,
  shape.by = NULL,
  colors = NULL,
  point.size = 8,
  opacity = 1,
  main = NULL
)
```

## Arguments

- pcaobj:

  A PCAtools `pca` object.

- components:

  Components to pair, by name. Default: the first 4.

- color.by, shape.by:

  Metadata columns to colour and shape the points by, or `NULL`.

- colors:

  Named vector of colours for the `color.by` levels. Unnamed levels fall
  back to the default palette.

- point.size:

  Marker size.

- opacity:

  Marker opacity.

- main:

  Optional plot title.

## Value

A `plotly` object, with the scores table as attribute `"table"`.

## See also

[`pcaPairsPlotServer()`](https://j-andrews7.github.io/sciVizModules/reference/pcaPairsPlotServer.md),
[`PCAtools::pairsplot()`](https://rdrr.io/pkg/PCAtools/man/pairsplot.html)
