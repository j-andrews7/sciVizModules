# Colours of the survival curves

Colours of the survival curves

## Usage

``` r
.km_palette(levels, palette.selection = NULL)
```

## Arguments

- levels:

  The strata.

- palette.selection:

  Colours named by stratum, or an unnamed vector used in level order, or
  `NULL` for the dittoColors defaults.

## Value

A character vector of colours named by stratum.
