# Heatmap defaults for the deHeatmap module

Heatmap defaults for the deHeatmap module

## Usage

``` r
.de_heat_defaults(frame, defaults = NULL)
```

## Arguments

- frame:

  A
  [`.de_heatmap_data()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_de_heatmap_data.md)
  result.

- defaults:

  The caller's defaults.

## Value

Defaults for the wrapped heatmap module.
