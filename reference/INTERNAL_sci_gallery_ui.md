# The gallery's UI

The gallery's UI

## Usage

``` r
.sci_gallery_ui(showcase, title, info)
```

## Arguments

- showcase:

  A
  [`.sci_module_showcase()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_sci_module_showcase.md)
  registry.

- title:

  The navbar and page title.

- info:

  The list from
  [`.sci_gallery_package_info()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_sci_gallery_package_info.md).

## Value

A tag wrapping the
[`shiny::navbarPage()`](https://rdrr.io/pkg/shiny/man/navbarPage.html).
