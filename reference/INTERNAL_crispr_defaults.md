# Default inputs for the CRISPR screen rank module

Default inputs for the CRISPR screen rank module

## Usage

``` r
.crispr_defaults(data, defaults = NULL)
```

## Arguments

- data:

  The gene summary (raw or tidy), or `NULL`. For an MLE summary the
  default `condition` is its first.

- defaults:

  A named list of user defaults, or `NULL`.

## Value

A named list of defaults.
