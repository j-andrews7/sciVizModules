# Fill colour of the QQ plot's confidence band

Fill colour of the QQ plot's confidence band

## Usage

``` r
.gwas_band_fill(color = "#7F7F7F", opacity = 0.25)
```

## Arguments

- color:

  The band colour; an unusable value falls back to grey.

- opacity:

  The fill opacity, clamped to 0-1; an unusable value falls back to
  0.25.

## Value

An `rgba()` colour string.
