# Default inputs for the sampleDistanceHeatmap module

Default inputs for the sampleDistanceHeatmap module

## Usage

``` r
.sd_defaults(se, defaults = NULL)
```

## Arguments

- se:

  A `SummarizedExperiment`, or `NULL`.

- defaults:

  A named list of user defaults, or `NULL`.

## Value

The wrapper's own defaults.
