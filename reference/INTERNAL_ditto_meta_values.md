# Fetch the values of a single metadata column

Fetch the values of a single metadata column

## Usage

``` r
.ditto_meta_values(object, meta)
```

## Arguments

- object:

  A dittoSeq-compatible object.

- meta:

  The name of a metadata column.

## Value

The metadata values, or `NULL` when unavailable.
