# Strata of a survival grouping column, in drawing order

A factor's level order, otherwise sorted, keeping only the values
present. Shared by
[`survivalCurve()`](https://j-andrews7.github.io/sciVizModules/reference/survivalCurve.md)
and the module's colour picker, so both list the strata in the same
order.

## Usage

``` r
.surv_levels(x)
```

## Arguments

- x:

  The grouping column.

## Value

A character vector.
