# Start one module in the gallery

Start one module in the gallery

## Usage

``` r
.sci_gallery_start_module(id, entry, data, output)
```

## Arguments

- id:

  The module id.

- entry:

  Its
  [`.sci_module_showcase()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_sci_module_showcase.md)
  entry.

- data:

  Its example dataset.

- output:

  The session's output.

## Value

The module server's return value, invisibly.
