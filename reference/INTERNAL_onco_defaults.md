# Default inputs for the oncoPlot module

Shared by the UI and the Reset handler. User values win.

## Usage

``` r
.onco_defaults(m, defaults = NULL)
```

## Arguments

- m:

  A result of
  [`.maf_table()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_maf_table.md).

- defaults:

  A named list of user defaults, or `NULL`.

## Value

A named list of defaults.
