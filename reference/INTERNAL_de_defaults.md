# Default inputs for the deHeatmap module

Default inputs for the deHeatmap module

## Usage

``` r
.de_defaults(x, defaults = NULL)
```

## Arguments

- x:

  The module's data (see
  [`.de_resolve()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_de_resolve.md)),
  or `NULL`.

- defaults:

  A named list of user defaults, or `NULL`.

## Value

The wrapper's own defaults.
