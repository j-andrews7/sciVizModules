# Normalise a user-supplied domain table

Normalise a user-supplied domain table

## Usage

``` r
.lollipop_domains(domains)
```

## Arguments

- domains:

  A data frame with start, end and label columns (any case;
  `Start`/`End`/`Label` as in maftools' table).

## Value

A data frame with `start`, `end` and `label`.
