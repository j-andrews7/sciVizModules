# The example bulk experiment: airway, as the airway package ships it

The airway RNA-seq counts (Himes et al. 2014; four airway smooth muscle
cell lines, each untreated or treated with dexamethasone) from the
airway data package, with `dex` relevelled so the untreated samples come
first.

## Usage

``` r
.se_example()
```

## Value

A `RangedSummarizedExperiment`.
