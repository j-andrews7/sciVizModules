# Cell order for the dittoHeatmap module

Cell order for the dittoHeatmap module

## Usage

``` r
.ditto_heatmap_order(object, order.by = "")
```

## Arguments

- object:

  A dittoSeq-compatible object.

- order.by:

  A metadata column to order the cells by, or `""` to keep the object's
  order.

## Value

Cell names.
