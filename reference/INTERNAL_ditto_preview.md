# Cell metadata of a dittoSeq object, for a read-only preview

Cell metadata of a dittoSeq object, for a read-only preview

## Usage

``` r
.ditto_preview(obj)
```

## Arguments

- obj:

  A `SingleCellExperiment`, `Seurat` or `SummarizedExperiment`.

## Value

Its `colData` as a data frame, or a one-row message when it has none
that can be read.
