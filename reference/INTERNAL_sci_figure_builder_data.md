# Datasets seeding the sciVizModules Figure Builder

The example datasets the modules in
[`sci_figure_builder_registry()`](https://j-andrews7.github.io/sciVizModules/reference/sci_figure_builder_registry.md)
are written for, plus the airway edgeR and limma-voom results as
alternatives to the DESeq2 ones. Loaded on demand rather than referenced
by name, since this package sets no `LazyData`.

## Usage

``` r
.sci_figure_builder_data()
```

## Value

A named list of data frames.
