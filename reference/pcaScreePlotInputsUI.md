# Input UI components for the pcaScreePlot module

This should be placed in the UI where the inputs should be shown, with
an `id` that matches the `id` used in the
[`pcaScreePlotServer()`](https://j-andrews7.github.io/sciVizModules/reference/pcaScreePlotServer.md)
and
[`pcaScreePlotOutputUI()`](https://j-andrews7.github.io/sciVizModules/reference/pcaScreePlotOutputUI.md)
functions.

## Usage

``` r
pcaScreePlotInputsUI(
  id,
  data,
  defaults = NULL,
  title = "Scree Plot Settings",
  columns = 2
)
```

## Arguments

- id:

  The ID for the Shiny module.

- data:

  A PCAtools `pca` object.

- defaults:

  A named list of default values for the inputs.

- title:

  An optional title for the UI grid.

- columns:

  Number of columns for the UI grid.

## Value

A Shiny tagList containing the UI elements

## Details

The module draws
[`pcaScreePlot()`](https://j-andrews7.github.io/sciVizModules/reference/pcaScreePlot.md)
for a PCAtools `pca` object: the variance each component explains, the
cumulative variance, and markers for the elbow and any components you
name. The inputs are organised into tabs via
[`VizModules::organize_inputs()`](https://j-andrews7.github.io/VizModules/reference/organize_inputs.html).

## Plot parameters and defaults

The following parameters can be accessed via UI inputs and/or the
`defaults` argument:

- `components` - Components to show (default: the first 10; PCAtools
  `components`)

- `show.cumulative` - Draw the cumulative line (default: TRUE; PCAtools
  `drawCumulativeSumLine`)

- `show.elbow` - Mark the elbow (default: TRUE; needs PCAtools
  installed)

- `mark.components` - Further components to mark, e.g. `"4"` from
  [`PCAtools::parallelPCA()`](https://rdrr.io/pkg/PCAtools/man/parallelPCA.html)
  (default: none; PCAtools `vline`)

- `bar.color` - Bar colour (default: "#1E90FF"; PCAtools `colBar`)

- `line.color` - Cumulative line colour (default: "#CD2626"; PCAtools
  `colCumulativeSumLine`)

The Legend, Axes, Lines and Plotly tabs carry the shared VizModules
inputs.
