# Defaults with maftools' variant-class colours

Defaults with maftools' variant-class colours

## Usage

``` r
.maf_color_defaults(defaults)
```

## Arguments

- defaults:

  A named list of user defaults, or `NULL`.

## Value

`defaults` with `palette.colours` seeded from maftools' palette where
the user gave no colour.
