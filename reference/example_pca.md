# Example PCAtools `pca` object (airway RNA-seq)

A principal component analysis of the airway RNA-seq experiment, in the
form [`PCAtools::pca()`](https://rdrr.io/pkg/PCAtools/man/pca.html)
returns, used by the PCAtools modules
([`pcaBiplotServer()`](https://j-andrews7.github.io/sciVizModules/reference/pcaBiplotServer.md),
[`pcaScreePlotServer()`](https://j-andrews7.github.io/sciVizModules/reference/pcaScreePlotServer.md),
[`pcaLoadingsPlotServer()`](https://j-andrews7.github.io/sciVizModules/reference/pcaLoadingsPlotServer.md),
[`pcaPairsPlotServer()`](https://j-andrews7.github.io/sciVizModules/reference/pcaPairsPlotServer.md)
and
[`pcaEigencorPlotServer()`](https://j-andrews7.github.io/sciVizModules/reference/pcaEigencorPlotServer.md)).
Eight samples (four airway smooth muscle cell lines, each untreated or
treated with dexamethasone); the PCA is on the variance-stabilised
counts of the 500 most variable genes. The object is a plain list, so it
loads without PCAtools installed.

## Usage

``` r
data(example_pca)
```

## Format

A `pca` object (a list) with elements:

- rotated:

  Sample scores: a data frame of 8 samples by 8 components

- loadings:

  Gene loadings: a data frame of 500 genes (named by symbol) by 8
  components

- variance:

  Percentage of variance explained by each component

- sdev:

  Component standard deviations

- metadata:

  Sample metadata: `dex` (treatment), `cell` (cell line), `avgLength`
  (mean read length), `lib.size` (total counts) and `size.factor`
  (DESeq2 size factor)

- xvars, yvars, components:

  Sample names, gene names and component names

## Source

Generated by `data-raw/generate_example_pca.R` from the `airway`
Bioconductor data package (Himes et al., 2014, PLoS One 9:e99625).
