# Load one example dataset from the catalogue

Load one example dataset from the catalogue

## Usage

``` r
.sci_example_dataset(name)
```

## Arguments

- name:

  A key of
  [`.sci_example_catalogue()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_sci_example_catalogue.md).

## Value

The dataset: a data frame, or the object or bundle its module takes.
