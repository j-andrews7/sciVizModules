# Per-residue pLDDT and chains from a model's C-alpha B-factors

Per-residue pLDDT and chains from a model's C-alpha B-factors

## Usage

``` r
.af_read_structure(path)
```

## Arguments

- path:

  A `.pdb` or `.cif` file (optionally gzipped).

## Value

A data frame with `chain`, `residue`, `plddt`.
