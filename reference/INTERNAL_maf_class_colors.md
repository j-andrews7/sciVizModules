# Colours for variant classes

Colours for variant classes

## Usage

``` r
.maf_class_colors(classes, colors = NULL)
```

## Arguments

- classes:

  The classes.

- colors:

  A named colour vector from the module's picker, or `NULL`.

## Value

A named colour vector covering `classes`: the picker's colour, then
maftools', then a grey.
