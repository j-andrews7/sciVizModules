# Build the samplePCA module's PCA from a transformed assay

Build the samplePCA module's PCA from a transformed assay

## Usage

``` r
.spca_build(se, mat, d)
```

## Arguments

- se:

  The `SummarizedExperiment`.

- mat:

  Its transformed assay.

- d:

  The wrapper's input values.

## Value

A PCAtools-shaped `pca` list.
