# Default inputs for the structureViewer module

Default inputs for the structureViewer module

## Usage

``` r
.structure_defaults(x, defaults = NULL)
```

## Arguments

- x:

  An object from
  [`read_structure()`](https://j-andrews7.github.io/sciVizModules/reference/read_structure.md).

- defaults:

  A named list of user defaults, or `NULL`.

## Value

A named list of defaults.
