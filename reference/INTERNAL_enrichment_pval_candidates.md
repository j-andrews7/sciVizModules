# Candidate significance / p-value column names for enrichment data

A single canonical, priority-ordered vector of the significance columns
produced by common enrichment tools, shared by the sunburst fill
detection in
[`goFanPlot()`](https://j-andrews7.github.io/sciVizModules/reference/goFanPlot.md)
and the dot plot p-value detector
([`.enrich_pval_col()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_enrich_pval_col.md))
so the two modules agree on what counts as a significance column.

## Usage

``` r
.enrichment_pval_candidates
```
