# Built-in colour palettes for the GO sunburst plot

Named vector of plotly continuous colorscales suitable for the `palette`
argument of
[`goFanPlot()`](https://j-andrews7.github.io/sciVizModules/reference/goFanPlot.md)
and the "Palette" UI input. Names are display labels; values are the
colorscale identifiers passed to plotly.

## Usage

``` r
.gofan_palettes
```
