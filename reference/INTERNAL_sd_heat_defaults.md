# Heatmap defaults for the sampleDistanceHeatmap module

Heatmap defaults for the sampleDistanceHeatmap module

## Usage

``` r
.sd_heat_defaults(frame, d, defaults = NULL)
```

## Arguments

- frame:

  A
  [`.sample_distance_data()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_sample_distance_data.md)
  result.

- d:

  The wrapper defaults from
  [`.sd_defaults()`](https://j-andrews7.github.io/sciVizModules/reference/INTERNAL_sd_defaults.md).

- defaults:

  The caller's defaults.

## Value

Defaults for the wrapped heatmap module.
