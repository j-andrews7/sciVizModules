# Default inputs for the samplePCA module

Shared by the UI, the server and the Reset handler. User values win.

## Usage

``` r
.spca_defaults(se, defaults = NULL)
```

## Arguments

- se:

  A `SummarizedExperiment`, or `NULL`.

- defaults:

  A named list of user defaults, or `NULL`.

## Value

The wrapper's own defaults.
