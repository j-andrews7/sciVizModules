# Example GSEA input (fgsea example data)

A gene set enrichment analysis bundle for the
[`gseaEnrichmentPlotServer()`](https://j-andrews7.github.io/sciVizModules/reference/gseaEnrichmentPlotServer.md)
module, in the form the module takes: gene-level statistics, gene sets,
and their fgsea results. Built from the example data of the fgsea
package (`exampleRanks`, `examplePathways`; MIT licence): a ranked list
of about 12,000 mouse genes (Entrez IDs) and the 40 Reactome pathways
fgsea ranks most significant for it.

## Usage

``` r
data(example_gsea)
```

## Format

A list with three elements:

- stats:

  Named numeric vector of gene-level statistics (names are Entrez IDs)

- pathways:

  Named list of 40 gene sets (vectors of Entrez IDs)

- results:

  The [`fgsea::fgsea()`](https://rdrr.io/pkg/fgsea/man/fgsea.html)
  results for those sets: `pathway`, `pval`, `padj`, `log2err`, `ES`,
  `NES`, `size`, `leadingEdge`

## Source

Generated by `data-raw/generate_example_gsea.R` from the fgsea package
(Korotkevich et al., 2016, bioRxiv, doi:10.1101/060012).
