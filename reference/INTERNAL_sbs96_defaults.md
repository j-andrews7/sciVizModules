# Default inputs for the mutationalProfile module

The wrapped bar module's mapping set to the classic 96-channel spectrum:
one bar per channel, coloured by substitution class, one panel per
sample. User values win.

## Usage

``` r
.sbs96_defaults(defaults = NULL)
```

## Arguments

- defaults:

  A named list of user defaults, or `NULL`.

## Value

A named list of defaults for
[`VizModules::plotthis_BarPlotServer()`](https://j-andrews7.github.io/VizModules/reference/plotthis_BarPlotServer.html).
