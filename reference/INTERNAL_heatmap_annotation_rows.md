# Column annotation rows for the wrapped heatmap module

Column annotation rows for the wrapped heatmap module

## Usage

``` r
.heatmap_annotation_rows(cols, side = "Top", prefix = "c")
```

## Arguments

- cols:

  Columns to show, top to bottom.

- side:

  `"Top"` or `"Bottom"` (`"Left"` / `"Right"` for rows).

- prefix:

  Row-name prefix.

## Value

A
[`multiDynamicInput()`](https://j-andrews7.github.io/VizModules/reference/multiDynamicInput.html)
row list, or `NULL`.
