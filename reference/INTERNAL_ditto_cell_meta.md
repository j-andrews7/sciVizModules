# Per-cell metadata of a dittoSeq object

Per-cell metadata of a dittoSeq object

## Usage

``` r
.ditto_cell_meta(object, cells)
```

## Arguments

- object:

  A dittoSeq-compatible object.

- cells:

  The cell names, in matrix column order.

## Value

A data frame of the atomic metadata columns, row names `cells`.
